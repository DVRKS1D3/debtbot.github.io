# debtbot.github.io

Сайт Telegram-бота [@debts_newbot](https://t.me/debts_newbot): что умеет бот,
история обновлений, вопросы и ответы и поддержка проекта. Статический сайт для
GitHub Pages без фреймворков: HTML плюс генератор на Node.js.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: разметка и собранные из данных блоки |
| `privacy.html` | Политика конфиденциальности |
| `assets/site.css` | Все стили обеих страниц: токены светлой и тёмной темы |
| `assets/theme.js` | Переключатель темы: системная → светлая → тёмная |
| `tools/check.py` | Проверка разметки, ссылок и согласованности с CSS |
| `releases.json` | **Источник правды** по релизам |
| `faq.json` | Вопросы и ответы (идут и в разметку, и в JSON-LD) |
| `site.json` | Базовый адрес сайта |
| `tools/build.mjs` | Генератор: релизы, FAQ, JSON-LD, RSS, sitemap, robots |
| `tools/make-assets.py` | Иконки и картинка для превью (Pillow) |
| `feed.xml` | RSS-лента обновлений (генерируется) |
| `sitemap.xml`, `robots.txt` | Служебные файлы для поисковиков (генерируются) |
| `assets/og-image.png` | Превью 1200×630 для Telegram и соцсетей |
| `assets/icon-192.png`, `assets/icon-512.png`, `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` | Иконки |
| `site.webmanifest` | Манифест для добавления на домашний экран |

## Как добавить обновление

1. Добавьте релиз в начало массива `releases` в `releases.json`:

   ```json
   {
     "version": "1.0",
     "date": "2026-11-01",
     "title": "Короткая суть релиза",
     "groups": [
       { "kind": "add", "items": ["Что появилось нового."] },
       { "kind": "fix", "items": ["Что починили."] },
       { "kind": "change", "items": ["Что изменилось в поведении."] }
     ]
   }
   ```

   Типы групп: `add` → «Новое», `fix` → «Исправлено», `change` → «Изменения».
   Ненужные группы не указывайте.

2. Пересоберите сайт:

   ```bash
   node tools/build.mjs
   ```

3. Закоммитьте изменённые файлы.

Порядок релизов в JSON можно не соблюдать — генератор сортирует их по дате и
версии. Всё производное обновляется само: счётчик обновлений, метка
«Последнее», тизер в шапке, RSS-лента, дата в футере и адреса вида `#v0-9`.
Повторный запуск сборки ничего не меняет.

Если забыть пересобрать, GitHub Actions (`.github/workflows/check-changelog.yml`)
упадёт на `node tools/build.mjs --check`.

## Как добавить вопрос в FAQ

Отредактируйте `faq.json` и пересоберите сайт. Один и тот же текст попадает
и в блок «Вопросы и ответы», и в разметку `FAQPage` для поисковиков, так что
дублировать его не нужно.

## Домен

Сейчас сайт живёт на `https://dvrks1d3.github.io/debtbot.github.io/`.
Чтобы переехать на свой домен:

1. поменяйте `baseUrl` в `site.json` (обязательно со слэшем на конце);
2. замените адрес в `index.html` (`canonical`, `og:url`, `og:image`,
   `twitter:image`) и в `privacy.html` (`canonical`);
3. пересоберите: `node tools/build.mjs` — `feed.xml`, `sitemap.xml` и `robots.txt`
   обновятся сами;
4. последним шагом создайте файл `CNAME` в корне репозитория: он сразу
   переключает GitHub Pages на новый домен, поэтому DNS должен быть настроен
   заранее.

Пункт 2 не обязательно делать вручную «на глаз»: если адреса в HTML разойдутся
с `site.json`, сборка упадёт и перечислит несовпадающие ссылки.

## Графика

Иконки и превью генерируются скриптом:

```bash
python tools/make-assets.py
```

Нужен Pillow и шрифты Segoe UI (`C:\Windows\Fonts`). Палитра задаётся в начале
`make-assets.py` — цвета иконок меняются в одном месте.

## Темы оформления

Все цвета собраны в `assets/site.css` в виде токенов. Светлая тема — значения
в `:root`, тёмная — их переопределение. Тёмные значения заданы дважды: в
`@media (prefers-color-scheme: dark)` (когда тема системная) и в
`:root[data-theme="dark"]` (когда её выбрали вручную). **Оба списка должны
совпадать** — за этим следит `python tools/check.py`.

Кнопка в шапке проходит по кругу: системная → светлая → тёмная. Выбор
хранится в `localStorage`, а `assets/theme.js` применяет его до отрисовки —
поэтому страница не мигает при загрузке. Без JavaScript кнопка не появляется,
а тема просто следует системной.

Чтобы поменять цвет, правьте токен, а не конкретное правило: тогда изменение
подхватят обе темы. Стили и скрипт в сборке не участвуют — после их правок
пересобирать ничего не нужно.

## Проверки

```bash
node tools/build.mjs --check   # index.html, feed.xml, sitemap.xml, robots.txt собраны из данных
python tools/check.py          # разметка, ссылки, якоря, согласованность классов с CSS
```

Обе команды выполняются в GitHub Actions на каждый push и pull request.

`check.py` ловит в том числе то, что не видно глазом: класс в разметке без
правил в стилях, расхождение списков токенов тёмной темы, якорь в никуда,
блочный элемент внутри строчного.

## Чего пока нет

- **Скриншотов бота.** Картинок интерфейса на сайте нет: их нужно снять из
  реального бота, а не рисовать. Когда они появятся, добавьте файлы в
  `assets/screens/` и вставьте их в раздел «Как это работает».
- **Telegram-канала.** Подписка пока только через RSS. Поле `channelUrl`
  в `site.json` оставлено под кнопку канала.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Если нужен сервер с корректными
путями:

```bash
python -m http.server 8000
```
